Guide

Prêt en 5 minutes

Configure et héberge ton bot simplement.

1

Créer l'application Discord

Va sur discord.com/developers, crée une application, puis dans "Bot" active les Privileged Intents (Server Members, Message Content, Presence).

2

Configurer le bot

Copie ton token dans config.json et ton Client ID dans le lien d'invitation.

token: "TON_TOKEN_BOT"
3

Installer et lancer

Installe les dépendances puis démarre le bot :

npm install && npm start
4

Héberger sur Render (24/7)

Dépose le code sur GitHub, crée un "Web Service" sur render.com. Le keepalive intégré maintient le bot actif sans Uptime Robot !

Build: npm install | Start: node bot.js
5

Configurer sur ton serveur

Invite le bot, puis utilise !setwelcome #salon, !setlogs #salon et !setauthorole @role pour tout configurer !

Prêt à booster ton serveur ? 🚀

Ajoute le bot en un clic et commence à utiliser toutes ses fonctionnalités.
